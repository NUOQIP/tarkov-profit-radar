# 塔科夫赚钱旁屏

面向 Escape from Tarkov 玩家的中文赚钱资讯网页。主要使用场景是主机运行游戏，旁边的笔记本持续显示可执行的赚钱建议。支持 PVE、PVP 常规和 PVP 赛季，三个市场分别计算。

已实现本地真实行情版：直接读取 tarkov.dev 的物品、商人直购、兑换与制作数据，支持 11 类物品和三个独立市场。网页打开时每 5 分钟检查更新，服务器统一缓存；显示逐项上游报价时间，不把网页刷新时间冒充报价时间。尚未公开部署。

真实行情页面采用三列独立滚动，可筛选武器、配件、护甲、弹药、钥匙、医疗、食品、交换品、装备、容器与其他物品。商人倒货支持“直购 + 兑换 / 只看直购 / 只看兑换”。旧版草图的价格、税费和长短线标签均为虚构演示，已不再作为当前产品入口。

本地运行需要 Node.js 22 或更新版本，无需安装第三方依赖：

```text
npm start
```

打开终端输出的本机地址，默认 `http://127.0.0.1:8787/`。`npm test` 检查税费、全部分类、禁售、报价时效、单格排序、堆叠、整枪预设、直购、兑换、制作和短线证据。

已通过 11 项计算与边界测试，并实际读取三个市场的独立行情。浏览器检查覆盖分类、直购筛选、弹药堆叠、燃料设置和市场切换；1366、1024 与 360 像素宽度均无横向溢出，手机窄屏改为纵向排列。

## 数据与收益边界

- 左列按预计单格净到手倒序。1 至 6 小时的旧报价标为“延迟报价净值”；更久或不可用时只显示明确标注的商人底价，避免把底价当作物品的全部市场价值。
- 倒货及材料成本只采用 60 分钟内、至少 3 条且没有明显偏离均价的报价。材料采用当前低价与 24 小时均价中较高者，不默认玩家解锁全部商人。缺价、狗牌等级等不支持的材料条件不会按零成本计算。
- 上架费读取各市场参数，默认无情报中心减免，可在“收益设置”调整。制作燃料未配置时显示“扣燃料前收益”；填入分摊成本后才显示预计净利。
- 武器用默认整套预设估值，弹药可明确切换单发或满堆叠。满状态估值不适用于残余容量、低耐久或已用钥匙，需在游戏内核对。
- 短线使用真实历史与当前报价共同判断，检查 7 日基准、24 小时变化及近 4 小时两个不同有效快照；当前报价仍须在 60 分钟内。按需核对候选，不宣称扫描完所有物品的历史。
- 尚未积累 30 日版本化材料成本与手续费证据，因此不生成长线绿色标签。原型中手工指定的“稳定”标记已停用。
- 已知活动品使用明确 ID 排除清单，暂不保证覆盖所有活动、不可获取状态和新物品。

## 核心体验

左列合并跳蚤卖出与单格价值，按每格净到手严格倒序；中列按每次倒货净利润倒序；右列按制作每小时净利润倒序。每列独立上下滚动，列标题固定，物品图、商人头像和设施图辅助识别。

短线指近期价格相对常态飙升，使用浅红底；长线指历史收益稳定，使用浅绿底。单价高、利润高或制作时间短，都不能单独判为短线。兼具两类时保留双标签，以浅红底突出当前溢价；普通波动和历史不足保持中性。

条目优先展示净到手、投入、材料、限购、时长、回报率和常态下利润。税费拆解、历史判断和计算规则按需展开。

## 已确定的范围

- 网站面向玩家公开访问，源码仓库初始设为私有。
- PVE 为默认市场，PVP 常规与赛季分别支持。
- QQ 当前先预留接入接口，机器人账号、群、发送权限和推送计划尚未启用。
- 数据首选 tarkov.dev JSON API，服务器统一采集并缓存。
- 用户等级与藏身处设置优先保存在本机；第一版无需注册。
