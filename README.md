# 塔科夫赚钱监控

面向《逃离塔科夫》玩家的中文赚钱看板：捡什么、卖给谁、倒什么货、搓什么更划算。

**[进入网站](https://tarkov-profit-radar-nuoqip.cloudy-otter-5459.chatgpt.site/) · [反馈问题](https://github.com/NUOQIP/tarkov-profit-radar/issues)**

支持 **PVE / PVP 常规 / PVP 赛季**，市场数据独立。适配桌面、旁屏、平板和手机，无需游戏账号。

## 功能

| 模块 | 重点 |
| --- | --- |
| 01 物品一览 | 按单件净利排序，搜索全品类、比较最低价 / 均价和商人差价 |
| 02 跑刀 | SPT 稀有度、涨价机会与单格价值综合排序，错落图标云 / 列表 |
| 03 商人倒货 | 直购与兑换、预设整枪、每次税后净利润 |
| 04 藏身处制作 | 每批最终收益、材料成本、工具与参考时薪 |

- 跑刀默认选中 **交换用品、饮食、情报、医疗物品**；只显示单格净值 **≥3万** 的物品，保留类型筛选和钥匙 / 武器配件 / 弹药包预设。
- 倒货和制作同时展示盈利与亏损。预设枪按同型号默认整枪报价计价，不额外计算配件卖出收入。
- 默认商人最高级、任务全完成；技能、商人、任务和生产设施仍可调整。收藏与条件保存在浏览器，可导入 / 导出。
- 活动道具（含橘子、沙拉、特殊燃料）保留在数据库，默认不展示，通过开关控制显示。跑刀速览排除特殊物品和地图。

## 怎么看颜色

| 标记 | 含义 |
| --- | --- |
| 浅红 · 涨价机会 | 高于7日常态或24小时参照，税后确有增收 |
| 浅金 · 长期高值 | 拾取在30日中至少24日有效，至少80%日期与较低价位区间达到每格3万，当前也达标 |
| 浅绿 · 亏损 | 扣除成本与手续费后的收益为负 |
| 报价数过低 | 报价少于10条，可能有虚标风险 |
| 卖某商人 | 商人回收比跳蚤扣税后更高 |

制作不计燃料运行成本，消耗材料照常计费，工具首购单列。倒货 / 制作的涨价机会必须盈利。材料数量、单价、合计紧邻成本展示。缺报价、缺成本、缺历史时保留未知状态，不补造收益或颜色。完整规则见 [产品说明](docs/product-design.md)。

## 本机运行

需要 **Node.js 22.13+**。轻量服务无需安装第三方依赖。

```sh
npm run local
```

打开 `http://127.0.0.1:8787/`。进程保持运行时，每5分钟采集三个市场；关闭网页不停止采集。

后台启动并自动打开网页：

```sh
node scripts/start-local.mjs
```

Windows 桌面快捷方式调用同一个启动器。重复启动会复用已有服务。端口、监听地址和数据目录可通过 `PORT`、`HOST`、`DATA_DIR` 配置；启动器会读取项目 `.env`。

| 位置 | 内容 |
| --- | --- |
| `.cache/v2/` | 行情、价格历史、收益档案、预计算看板 |
| `.cache/logs/` | 后台服务运行日志 |
| `.cache/server.pid` | 启动器记录的服务进程号 |

## 公测部署

现有公开网址使用 **Cloudflare Worker + R2**，与本机服务独立运行。没有域名和固定公网入口时，可先用现有网址公测。

新增 **腾讯云香港部署包**：面向 Ubuntu 24.04，含开机启动、异常重启、每日收益档案备份与升级回退。先用一个月验证实际网络和容量，安装与上线步骤见 [腾讯云部署](docs/tencent-cloud.md)。

```sh
node scripts/package-tencent.mjs
```

本机服务默认仅监听本机，桌面快捷方式不会自动获得公网地址。其他部署方式和容量边界见 [部署说明](docs/deployment.md)。

托管版本构建：

```sh
npm ci
npm run build
npm start
npm test
```

## 数据与性能

行情来自 [tarkov.dev](https://tarkov.dev)，稀有度采用固定版本的 SPT 公开物品库。排序权重为单格价值 50%、常见程度 40%、短线 10%，详见 [SPT 数据与排序](docs/spt-rarity.md)。前台每5分钟检查，新行情15秒后自动应用，也可暂停或立即更新。

- 服务端每周检查 SPT 上游并保存结果，供后续管理后台使用；玩家页面不展示版本或检查入口，数据替换仍需校验后发布。
- 行情、标签摘要、收益档案合并读取；本批标签计算完成后一次展示。
- “搜索仓库”加载动画支持减少动态效果；失败可重试，已有行情继续保留。
- 历史扫描在后台进行，完整走势图按需加载；缓存命中不等待上游请求。
- 本机服务支持 gzip、ETag、条件请求和并发更新合并。

传输体积与标签计算的本机测量见 [性能记录](docs/performance.md)；公网加载还受网络与图片缓存影响。
