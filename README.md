# 塔科夫赚钱旁屏

面向 Escape from Tarkov 玩家的中文赚钱资讯网页。主要使用场景是主机运行游戏，旁边的笔记本持续显示可执行的赚钱建议。支持 PVE、PVP 常规和 PVP 赛季，三个市场分别计算。

当前阶段为需求与交互设计，尚未发布实时应用。交互预览中的金额、手续费、趋势标签均为演示数据，不能用于当前交易决策。

- [产品设计与验收标准](docs/product-design.md)
- [数据来源与可行性核验](docs/data-findings.md)
- [交互预览源文件](prototype/side-screen-radar.fragment.html)

交互预览采用三列独立滚动，可切换市场、筛选长短线、搜索物品或材料，并点击条目查看收益明细。仓库保留其源文件，以便后续实现复用设计。

已在浏览器检查 1366 × 768、1024 × 768 三列布局及 360 像素窄屏，无横向溢出；52 个物品、材料、商人和设施图像元素加载成功。单格倒序、红绿分类、独立滚动、市场切换、收益明细、材料搜索和无结果状态均已验证。正式版的实际数据、125% 系统缩放和网络故障体验仍需实施后验证。

## 核心体验

左列合并跳蚤卖出与单格价值，按每格净到手严格倒序；中列按每次倒货净利润倒序；右列按制作每小时净利润倒序。每列独立上下滚动，列标题固定，物品图、商人头像和设施图辅助识别。

短线指近期价格相对常态飙升，使用浅红底；长线指历史收益稳定，使用浅绿底。单价高、利润高或制作时间短，都不能单独判为短线。兼具两类时保留双标签，以浅红底突出当前溢价；普通波动和历史不足保持中性。

条目优先展示净到手、投入、材料、限购、时长、回报率和常态下利润。税费拆解、历史判断和计算规则按需展开。

## 已确定的范围

- 网站面向玩家公开访问，源码仓库初始设为私有。
- PVE 为默认市场，PVP 常规与赛季分别支持。
- QQ 当前先预留接入接口，机器人账号、群、发送权限和推送计划尚未启用。
- 数据首选 tarkov.dev JSON API，服务器统一采集并缓存。
- 用户等级与藏身处设置优先保存在本机；第一版无需注册。

## 后续实施顺序

1. 建立按市场隔离的数据采集、手续费计算与可用性过滤。
2. 实现三列旁屏、独立滚动、搜索、收藏和个人解锁条件。
3. 累积历史快照，验证长短线指标与降价后的收益。
4. 完成公开部署、失效数据提示和运行监控。
5. 在确认 QQ 通道权限后接入查询与推送。
