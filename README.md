# 塔科夫赚钱监控 · LOOT RADAR

适配桌面宽屏、笔记本、平板与手机的中文行情看板。PVE、PVP 常规、PVP 赛季分别取数、计算和保存个人条件；真实数据来自 [tarkov.dev](https://tarkov.dev)，不登录游戏、不自动交易。

## 使用

| 页签 | 内容 | 排序 |
| --- | --- | --- |
| 捡什么 · 卖什么 | 物品图、跳蚤挂价、税后净到手、占格、商人底价 | 单格净到手倒序 |
| 商人倒货 | 直购 / 兑换、材料、商人等级、限购、投入、税后净利润 | 每次预计净利润倒序 |
| 藏身处制作 | 材料、工具、时长、产出、最终净利、参考时薪 | 每批最终净利润倒序 |

三个主要页签和物品一览，各自记住筛选。界面采用蓝灰工业底色、金色实心标志、地形线背景和轻量动效；支持减少动态效果偏好。桌面侧栏、手机底部导航，列表随宽度增加列数，低高度窗口压缩工具栏。底部提供标准 / 紧凑两档网格密度并记住选择。筛选、角色条件和明细使用抽屉，入口始终可见。支持全部 12 类物品、搜索、收藏、预算和收益筛选、深浅外观。已移除自选大屏、单件 / 满堆叠切换、卡片小折线图和独立长线筛选；旧大屏链接转到捡卖页。

倒货和制作默认同时显示盈利与亏损条目，按最终净利润倒序。近战武器、武器预设、直购和兑换统一出现在倒货列表，不再提供互斥的倒货类型或货源范围切换。武器预设保留自身的获取成本，使用对应基础武器的跳蚤报价与手续费计算净回款，配件收入不计入。缺失报价或材料成本的倒货条目显示待估值并排在最后，不当作零成本。护甲套装等装备预设保留自己的估值。

捡卖默认选中“全部物品”，可切换“跑刀杂物”：只包含交换品、饮食和情报，按单格净到手倒序。这是品类范围，不宣称知道地图刷新概率。升级时旧默认选项一次性恢复为全部物品，后续手动选择仍会保存。最低报价与 24 小时均价同时显示。

**物品一览**保留当前市场的全部源物品，包括无报价、跳蚤禁售、货币、机匣和改装预设。按单格净值倒序，未知值排在最后；支持中英文 / 简称 / ID 搜索、分类、出售状态、收藏筛选和分页，手机使用卡片排版。活动开关与监控共用，其他筛选各自保留。不提供持久隐藏操作，旧隐藏记录自动忽略；每页有明确的重置筛选入口。

一览同时展示跳蚤税后到手与商人回收，标出更优渠道。物品详情可继续查看相关赚钱路线和配方材料；分享链接可直接打开禁售或缺报价物品，不受推荐筛选影响。

**活动物品始终保留在源数据库中。** 筛选抽屉内“包含活动限定物品”默认关闭，按市场记住选择；打开后，已识别活动品及相关兑换 / 制作参与筛选和估值，并带活动标签。主界面显示可移除的筛选标签。识别规则是可维护的显式 ID 清单，不能保证覆盖所有未来活动。

点击条目查看 7 / 30 日真实报价、税费和材料拆解、解锁条件，以及目标挂价、24 小时均价、回到 7 日常态的收益试算。走势图支持鼠标、触屏和方向键查看具体日期与价格。所有场景重新计算手续费；物品出售支持输入积攒数量。明细移除重复长备注和收益拆解中的占格。

“我的条件”首次预选商人最高级、全部已知任务完成；保留管理技能、商人忠诚度、任务复选框，并可选择参与推荐的生产设施。商人使用英文名，排除剧情角色。玩家与设施按最高级计算，情报中心 3 级；移除等级、材料成本口径和游戏版本控件。修改后立即影响估值和可执行条件，按市场保存，可一键恢复满进度。制作不计燃料运行成本；工具首次购置单列。收藏与设置保存在设备，可导入 / 导出。

## 红绿标签与准确性

- **7 日急涨浅红**：当前最低价比约 7 日前至少高 20%，税后增收至少 10%。需要至少 6 日历史覆盖、参照区间至少 2 条有效报价、近 4 小时至少 2 次间隔 15 分钟的高价确认，当前报价须在 1 小时内。参照价取距今 6–8 日前的有效报价中位数。无需最近 24 小时持续上涨，少于 1 万的真实增收也可识别。长期贵价本身不触发。
- **拾取长线浅绿**：30 个完整 UTC 日中至少 24 日有有效报价，按现行手续费回算后，至少 80% 日期及下四分位达到每格 3 万，当前也达到门槛。它是历史价格回算的长期高值，不是历史实际成交利润。
- **倒货 / 制作长线浅绿**：依赖自采的配方与费率版本一致的配对成本档案。至少 24 日、每日至少 4 次观测，包含亏损样本；较差区间仍有正收益。角色条件、费率或材料口径与档案不同不沿用标签。上线初期不伪造这些标签。
- **时效**：60 分钟内、至少 3 条报价且无明显异常为近期参考；1–6 小时标“报价延迟”，只作估算。短线、“仅显示条件已确认”及 QQ 摘要排除延迟报价。更旧、禁售或缺报价的拾取条目只显示可用商人底价。
- 材料统一按采购成本：跳蚤取当前最低扫描价与 24 小时均价中较高者，并与已解锁商人价比较。没有可核实成本时不生成虚假利润。
- 工具不重复扣成本，首购金额独立列出。不扣燃料运行分摊，配方消耗品本身仍计入成本。使用配方基础时长，未模拟技能加速。比特币矿场和随机祭品产出不作为固定制作推荐。
- API 未提供报价实际耐久、容量、钥匙余次或商人实时库存；估值不是成交保证。不把报价数量称为销量，不跨市场补价。

## 运行与部署

Node.js 22.13 或更新版本。本地轻量服务无需第三方运行依赖：

```sh
npm run local
```

地址为 `http://127.0.0.1:8787/`。前台每 5 分钟检查更新；本地服务进程存活时，即使关闭浏览器也每 5 分钟采集三个市场。`.cache/v2/` 保存行情、历史及收益档案，更新失败保留最后成功快照并显示时间。

托管版使用 Vinext / Cloudflare Worker，R2 保存公共市场数据。`.openai/hosting.json` 固定站点身份。构建和托管运行环境本地预览：

```sh
npm ci
npm run build
npm start
npm test
```

托管前台每 5 分钟检查；关闭网页后的采集由独立计划触发 `/api/collect`。实际启用状态以 Sites 保存结果为准，浏览器定时器不等于后台计划。详见 [后台更新](docs/collection.md)。

测试覆盖税费、全部分类、跑刀杂物范围、禁售、时效、堆叠、整枪预设、直购 / 兑换 / 制作、活动开关、机会成本、不计燃料、7日涨价证据、每批排序、长期覆盖、异常输入、亏损留档与并发保存。

托管端只在单次请求内合并正在执行的读取，防止已中断请求拖住后续访问；已完成的行情数据仍可缓存复用。前端请求超过 45 秒会恢复刷新入口并显示超时原因。
