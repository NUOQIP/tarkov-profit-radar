# 塔科夫赚钱监控

面向《逃离塔科夫》玩家的中文赚钱看板：捡什么、卖给谁、倒什么货、搓什么更划算。

**[进入网站](https://tarkovlootradar.lanluz.xin/) · [反馈问题](https://github.com/NUOQIP/tarkov-profit-radar/issues)**

支持 **PVE / PVP 常规 / PVP 赛季**，市场数据独立。适配桌面、旁屏、平板和手机，无需游戏账号。

## 功能

| 模块 | 重点 |
| --- | --- |
| 01 物品一览 | 按单件净利排序，搜索全品类、比较跳蚤最低价和商人差价 |
| 02 跑刀 | 常见好物居中、大小错落的图标云 / 列表；随手查价 |
| 03 商人倒货 | 直购与兑换、预设整枪、每次税后净利润 |
| 04 藏身处制作 | 每批最终收益、材料成本、工具与参考时薪 |

- 跑刀默认选中 **交换用品、饮食、情报、医疗物品**；浏览推荐单格净值 **≥3万** 的物品；搜索不限价值与类型，「筛选·X」显示已选类型数量，提供钥匙 / 武器配件 / 弹药包临时预设，再点一次恢复自定义选择。恢复默认入口位于筛选面板。
- 常见好物优先展示；组内排序采用 **常见程度 50% · 单格价值 40% · 短期涨价 10%**。价值评分在 100万 / 格封顶；排序用于拾取提醒，不代表真实刷率。
- 倒货和制作同时展示盈利与亏损。预设枪按同型号默认整枪报价计价，不额外计算配件卖出收入。
- 倒货和制作卡片展示报价、含手续费的总成本与最终净利；明细保留分项成本、手续费和24小时均价，材料用量与单价紧邻成本。
- 默认玩家79级、设施和商人最高级、任务全完成；等级、设施、商人和任务均可调整。玩家等级影响跳蚤解锁，情报中心影响手续费。设置按市场保存，备份入口位于条件面板底部。
- 跑刀筛选默认勾选「无视跳蚤等级限制」，取消后按实际等级估值。图标云、列表、筛选、排序和物品明细采用同一设置，选择按市场保存；跳蚤禁售、活动筛选和设施税费始终生效。
- 其他页面在等级不足时按商人回收计算展示金额和排序；倒货、制作扣除成本后显示净利，亏损照常保留。跳蚤税后参考价仅用于对比，负差额显示具体金额。
- 默认使用邮箱＋密码登录，也可用邮箱验证码；支持 QQ、163、Outlook、Gmail 和企业邮箱。注册、找回密码和设置密码均验证邮箱。登录保持90天，活跃时自动续期；跨设备同步条件、收藏与筛选，访客可继续浏览。
- 物品评论绑定账号昵称，每页5条；管理端可搜索、隐藏与恢复评论。邮箱配置见 [账号与邮箱](docs/accounts.md)。
- 活动道具（含橘子、沙拉、特殊燃料）保留在数据库，默认不展示，通过开关控制显示。跑刀浏览排除特殊物品和地图；搜索可以查价。

## 怎么看颜色

| 标记 | 含义 |
| --- | --- |
| 浅红 · 涨价机会 | 高于7日常态或24小时参照，税后确有增收 |
| 浅金 · 长期高值 | 拾取在30日中至少24日有效，至少80%日期与较低价位区间达到每格3万，当前也达标 |
| 浅绿 · 亏损 | 扣除成本与手续费后的收益为负 |
| 报价数过低 | 报价少于10条，可能有虚标风险 |
| 卖某商人 | 商人回收更划算，或无法通过跳蚤出售 |
| 跳蚤禁售 / 跳蚤 Lv.X | 游戏禁售，或当前玩家等级未达到交易要求 |

制作不计燃料运行成本，消耗材料照常计费，工具首购单列。倒货 / 制作的涨价机会必须盈利。材料数量、单价、合计紧邻成本展示。缺报价、缺成本、缺历史时保留未知状态，不补造收益或颜色。完整规则见 [产品说明](docs/product-design.md)。

## 本机运行

需要 **Node.js 24+**，推荐24 LTS；首次运行先安装依赖。轻量服务使用 SQLite，邮件通过 Nodemailer 发送。

```sh
npm ci
npm run local
```

打开 `http://127.0.0.1:8787/`。进程保持运行时，每5分钟采集三个市场；关闭网页不停止采集。

后台启动并自动打开网页：

```sh
node scripts/start-local.mjs
```

Windows 桌面快捷方式调用同一个启动器。重复启动会复用已有服务。端口、监听地址和数据目录可通过 `PORT`、`HOST`、`DATA_DIR` 配置；启动器会读取项目 `.env`。

| 位置 | 内容 |
| --- | --- |
| `.cache/v2/` | 行情、价格历史、收益档案、预计算看板 |
| `.cache/v2/media/` | 物品图片缓存，可重新下载 |
| `.cache/v2/community/comments.sqlite` | 评论数据库，需备份 |
| `.cache/v2/community/accounts.sqlite` | 账号与条件数据库，需备份 |
| `.cache/v2/admin/mail.json` | 发信配置与授权码，私密保存 |
| `.cache/logs/` | 后台服务运行日志 |
| `.cache/server.pid` | 启动器记录的服务进程号 |

## 公测部署

公测网站部署在 **腾讯云香港**，通过 HTTPS 访问，无需本机保持开机。三个市场每5分钟自动采集，服务开机自启，每日备份。

使用 **Ubuntu 24.04 + Node 24 LTS + Nginx**，无需独立数据库。域名证书自动续期；后台登录、分类修改和行情数据由同一服务管理。部署、升级与恢复见 [腾讯云部署](docs/tencent-cloud.md)。

```sh
node scripts/package-tencent.mjs
```

已有实例的更新包：`node scripts/package-update.mjs 20261023`。包内附执行说明，自动备份、校验与回滚；只打包程序，账号、评论和邮件配置沿用服务器数据。

本机服务默认仅监听本机，桌面快捷方式用于本地调试。原 Sites 预览与腾讯云数据独立，正式入口以上方网址为准。其他部署方式和容量边界见 [部署说明](docs/deployment.md)。

托管版本构建：

```sh
npm ci
npm run build
npm start
npm test
```

## 后台管理

Node 服务的 `/admin/` 提供密码保护的管理端：编辑活动分类与稀有度、管理评论、配置验证码邮箱、查看行情与上游状态。分类同步三个市场，自动采集不会覆盖人工设置。

公网管理使用 HTTPS；未设置密码时禁止登录。密码设置、数据位置与备份见 [后台说明](docs/admin.md)。管理页面不出现在玩家导航中。

## 数据与性能

行情来自 [tarkov.dev](https://tarkov.dev)，稀有度采用固定版本的 SPT 公开物品库，详见 [SPT 数据与排序](docs/spt-rarity.md)。前台每5分钟检查，新行情15秒后自动应用，也可暂停或立即更新。

公共行情使用 IndexedDB、ETag 与 Brotli；再次打开先恢复完成标色的缓存，再核对更新。生产脚本合并压缩并按内容版本缓存，物品图缓存30天。账号与评论写入不进入公共缓存。实测记录见 [性能](docs/performance.md)。

- 服务端每周检查 SPT 上游，结果在管理端展示；玩家页面不展示版本或检查入口，数据替换仍需校验后发布。
- 行情、标签摘要、收益档案合并读取；本批标签计算完成后一次展示。
- “搜索仓库”加载动画支持减少动态效果；失败可重试，已有行情继续保留。
- 历史扫描在后台进行，完整走势图按需加载；缓存命中不等待上游请求。
- 本机服务支持 gzip、ETag、条件请求和并发更新合并。
- 图片由本站缓存，浏览器缓存7天；服务端合并相同下载、限制上游并发，旧缓存可在上游失败时继续使用。列表更新复用图片节点，减少重新加载。

传输体积与标签计算的本机测量见 [性能记录](docs/performance.md)；公网加载还受网络与图片缓存影响。
