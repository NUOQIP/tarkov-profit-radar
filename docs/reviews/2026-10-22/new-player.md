# 萌新玩家视角走查

## 画像与任务

2026-10-22，本地站点模拟走查。画像：知道塔科夫基本玩法，但不熟悉商人英文名、物品简称和经济计算；想知道捡什么、卖给谁、买哪些材料去兑换或制作。本报告不是招募真人测试，也不是游戏内实测。

使用独立隐藏 IAB 标签页，实际点击界面与阅读详情；未读原始游戏数据，未修改产品、发布或重启服务。评价基于约 1280×720 桌面视口。

## 实际走查步骤

1. 从 PVE 物品一览进入，观察首屏 C-3、T-7 和金色钥匙卡片；打开 C-3 明细，核对最低价、手续费、扣税后到手与商人回收差额。
2. 搜索“螺丝”，得到平头螺丝刀、长平头螺丝刀、螺丝刀三项。打开筛选，看到分类、最低单格净值、新鲜报价及长期高值说明，随后取消。
3. 进入跑刀，尝试“看看钥匙”；刷新到本轮新版后又实际点击“看看弹药包”，看到 M80 ×20、SS190 ×50 等项目，再恢复默认。未把本轮变更中间状态当作缺陷。
4. 进入倒货，打开首项 314 钥匙明细，检查徽章 ×25 的进货成本、手续费、净回款及任务条件；看到相关路线中的负收益记录。
5. 进入藏身处，打开电线明细，核对材料成本 140,000、每批净到手 483,838、最终净利 343,838、产出 ×8 和参考时薪。
6. 打开“我的条件”，查看技能、藏身处、任务分组：技能显示 0；设施全部参与推荐；任务显示全部完成、499/499。未保存变更。
7. 在藏身处切换 PVP 常规，看到电线利润变成 79,549、榜首变为热棒；再切回 PVE。
8. 对藏身处实际应用“酿酒器”设施筛选，得到私酒一项，净利 −58,470、时薪 −19,136，确认亏本制作仍可发现。

## 有效设计

- 四个功能固定在侧栏，中文标题明确，切页后搜索独立，首次探索不容易迷路。
- 搜索不用提交，物品图像、简称和全名详情搭配，找熟悉物资很快。
- 明细能解释大部分金额：电线批量产出、材料来源与单价、税费、最终净利完整；负收益路线也保留。
- 跑刀用“万/格”降低大数字阅读成本，快捷预设有选中状态，新增弹药包预设把每包发数显露出来。
- 延迟报价、低报价数可见，避免把极高收益完全理解为稳赚。
- 满商人、全部任务完成的默认符合本项目要求；条件分组、取消按钮和按市场保存的提示容易找到。

## 发现问题

### P1：倒货详情缺少当前路线的完整执行摘要

- 复现：PVE → 倒货 → 首项 314 钥匙 → 打开明细。
- 证据：列表明确写 Jaeger LL4、兑换、限购 1；详情突出利润、银徽章 ×25 和任务，但没有重复显示该路线的商人、等级、限购，也没有一句说明兑换后卖到哪里。相关路线却显示了 Jaeger LL3 的另一条亏损路线。
- 玩家影响（推测）：萌新进入详情后失去执行上下文，可能把相关路线当成当前方案，或记不住应找哪个商人。
- 具体改法：在详情金额下加一行紧凑执行摘要“买徽章 ×25 → Jaeger LL4 兑换 → 跳蚤出售”，并就近保留限购；不额外扩张列表备注。

### P1：金额称谓跨页含义需要一个局部帮助入口

- 复现：物品一览 C-3 卡片大字 18,507,598“净利/个”；进入详情看见它是跳蚤扣税后到手，未扣购买成本；再进入倒货/制作，净利会扣进货/材料成本。
- 证据：C-3 最低价 30,000,000、上架费 11,492,402，差为卡片大字；电线明细另外扣材料成本 140,000。
- 玩家影响（推测）：从“赚钱监控”首次进入的玩家可能把物品页当买入卖出套利榜，误以为正数意味着买后也能赚。
- 具体改法：遵守用户保留“净利/个”和简洁文字的偏好，在该标签旁放问号或点按解释：“按已持有物品计算，扣出售费用”；倒货/制作同入口解释已扣材料成本。不要给所有卡片增加常驻长说明。

### P2：颜色和涨幅时间窗的关系不易自行确认

- 复现：物品首屏同时出现蓝灰 C-3、粉红 T-7、金色钥匙；跑刀又出现 24h 与 7日涨幅。
- 证据：颜色可见，卡片有“7日+38%”“长期高值”等文字；本次打开的普通筛选只解释长期高值门槛，没有看到短期背景色规则入口。
- 玩家影响（推测）：萌新能理解“有不同等级”，但无法确定粉红表示涨价、稀有还是危险，也难判断 24h/7日采用哪个基准。
- 具体改法：在“涨价机会”或页脚已有帮助附近提供小型图例，点击才展开颜色与时间窗说明，保留现有卡片简洁度。

### P2：默认条件在列表层缺乏简短状态反馈

- 复现：首次进入倒货，首屏大量 LL4 方案；只有打开“我的条件”才看到“满商人·全任务完成”。
- 证据：设置内状态明确；列表首屏没有同等可见的条件摘要。技能页同时显示藏身处管理技能为 0，本次未验证这是否为设计允许的技能默认。
- 玩家影响（推测）：真实进度未满的新用户可能先尝试无法执行的方案，之后才发现工具默认按最高进度计算。
- 具体改法：在“我的条件”按钮的帮助/状态中显示“当前按满进度计算”，点击直接进入设置；保持默认全满，不强制新手问卷。技能 0 是否符合“默认全满”需产品确认，不在本报告直接定为错误。

## 首选三项迭代建议

1. 倒货详情补齐当前路线的商人/等级/兑换→出售摘要，优先消除执行歧义。
2. 给净利标签增加按需解释，区分持有物品出售到手与扣进货成本后的利润。
3. 用一个可展开帮助入口说明短期背景色、24h/7日涨幅和长期高值；不增加卡片常驻文字。
