# 倒货与藏身处经营视角实测

## 画像与目标
模拟熟悉商人兑换与生产的经营玩家：先判断本金与每批回款，再安排在线短周期生产或离线长周期生产。2026-10-22 在本地网站通过独立隐藏浏览器标签实际操作；这是代理的玩家视角评审，不是真人访谈，也未验证游戏内成交。

## 实际步骤
1. PVE 倒货首页查看直购、兑换、武器预设；打开 SA-58 AUT 详情。
2. 筛选近战武器，得到 8 条路线；查看正收益 M-2、负收益 MPL-50、Red Rebel 及待估值物品，打开 MPL-50 详情。
3. 重置倒货筛选，进入藏身处；对比电线、热棒、两条电路板配方的每批净利、时薪、耗时和工具。
4. 切换酿酒器，查看亏本私酒完整明细；收藏私酒并进入收藏，再取消收藏。
5. 打开我的条件，检查技能、设施、任务；搜索“电池换新”，暂时取消一项后点击取消，不保存。
6. 切换 PVP 常规再回 PVE，访问物品一览和跑刀页；回藏身处搜索“螺丝刀”，得到 18 条相关配方并查看电路板工具成本。
7. 恢复本人修改的收藏、市场、倒货/制作筛选；未清空任何存储，关闭本人测试标签，服务保持运行。

## 有效设计
- 经营主数字够明确。倒货区分“净利/次”，制作区分“净利/批”，制作同时给产出数、耗时与时薪，避免把电线 ×8 的总收益误读成单件收益。
- 亏本机会确实保留：近战筛选中 MPL-50 为 −46,549，Red Rebel 为 −1,741,847；PVE 私酒为 −58,470/批。不会把玩家想核算的配方直接藏起来。
- 直购、兑换、武器预设首屏均可找到；进货成本、回报率、限购、材料数量直接可见，低报价数与延迟提醒能帮助识别不可靠的高利润。
- 酿酒器是明确的设施选项，单独切换后仅剩私酒；私酒明细能复核 281,530 净到手 −340,000 材料 = −58,470 最终净利。
- 工具说明准确易懂：电路板详情明确“螺丝刀，可复用工具，29,889，首购另计”，材料成本只计 13,000 的气体分析仪。
- 搜索工具名也能检索配方；收藏能保留负收益配方。两个经营页没有涨价机会筛选，物品页保留；本次玩家界面未见 SPT 管理入口。
- PVE/PVP 切换保留当前制作页并更新数据（178 条对 174 条），全站导航位置稳定。

## 问题

### P1：卖商人标签与正在展示的净利口径容易混淆
- 复现：PVE → 倒货 → 筛选近战武器 → MPL-50 → 明细。
- 证据：列表和详情均标“卖 Jaeger”；详情同时显示净回款 1,449、最低价 1,675、上架手续费 226、成本 47,998、净利 −46,549。1,449 正好是 1,675−226，详情没有 Jaeger 的报价或两路线比较。
- 玩家影响：标签看起来像当前推荐出售路径，但主数字仍像跳蚤口径，玩家无法判断按哪条路线执行，可能错过更高回款。这里确认的是说明冲突，未据此断言后台公式错误。
- 建议：详情直接列“跳蚤净到手 / 最佳商人到手 / 高出多少”，给当前利润数字加路径说明；若标签只提醒另一条路线更划算，写成“商人更划算”并提供对应数字。

### P1：设施条件只能开关推荐，无法表达设施等级
- 复现：我的条件 → 藏身处。
- 证据：七个设施均只有“参与推荐”复选框和“全部选中”；配方卡却有工作台 Lv.1/Lv.2、营养部 Lv.3 等等级。
- 玩家影响：玩家想从满级默认改成工作台 1 级时，只能保留所有工作台配方或关闭整个工作台，不能准确表达自己的进度。
- 建议：默认最高等级保持不变；每个设施增加等级选择，“不参与推荐”保留为独立开关，并让仅看条件已满足按等级执行。

### P2：同名任务缺少区分信息
- 复现：我的条件 → 任务 → 搜索“电池换新”。
- 证据：出现两个完全相同的“电池换新”复选框；全量列表另有重复“独立的代价”“纺织业”等名称。
- 玩家影响：想精确取消尚未完成任务时不知道应该选哪一个，降低条件编辑可信度。
- 建议：补商人、任务分支或版本副标题；若为同一任务重复数据则合并。不要只露内部 ID。

### P2：武器预设的估值规则没有在金额旁解释
- 复现：倒货首页 → SA-58 AUT 详情。
- 证据：显示武器预设名称、270,000 最低价、42,000 进货成本与“查看基础武器/机匣”按钮，但金额区没有“按基础武器报价，不含配件收益”的文字。
- 玩家影响：熟悉预设配件的玩家可能以为整套预设直接按当前名称估价，难以理解不同改装预设为何共用卖价。
- 建议：保留用户指定算法，在金额旁增加一句固定说明并显示所对应基础武器名称。

### P2：缺少按时薪或离线时长比较制作的快捷方式
- 复现：藏身处全部设施首屏对比电线、热棒和电路板。
- 证据：电线 +343,838/批、时薪174,340；热棒 +279,506/批、12小时、时薪23,292；电路板另一条配方仅 +119,602/批但时薪217,458。页面未见时薪/耗时排序控件。
- 玩家影响：在线反复收菜和睡前挂长生产需要不同选择，按批次净利的列表让高效率短配方较难被发现。
- 建议：保留默认每批最终净利排列；提供简洁的“按时薪”“适合离线”比较入口或耗时范围，不需要加入涨价机会过滤。

## 最值得做的3项
1. 把卖商人提醒与当前净利的出售路径讲清楚，给出可核算的双路线比较。
2. 为设施增加可编辑等级，让默认满进度与玩家真实进度都能成立。
3. 补充武器预设估值说明与任务同名区分，减少经营决策前的猜测。
