# 部署与公测

## 当前入口

公开站点：<https://101.33.32.33/>

网站已公开，代码仓库权限与网站权限分开管理。本机与云端各有自己的数据缓存，不自动同步。QQBOT 暂缓，当前没有机器人配置或群消息发送。

## 本机服务

1. 安装 Node.js 24 或更新版本，并在项目目录运行 `npm ci` 安装依赖。
2. 在项目目录运行 `node scripts/start-local.mjs`，或双击桌面“塔科夫赚钱监控 · 启服”。
3. 浏览器打开 `http://127.0.0.1:8787/`。首次采集可能稍慢，后续使用缓存。
4. 保持电脑开机联网。浏览器可以关闭，睡眠、关机和断网会中断本机服务。

启动器读取 `.env`，可配置 `PORT=8787`、`HOST=127.0.0.1`、`DATA_DIR`。默认仅监听本机；不要把 `.cache`、日志、环境变量或整个项目目录作为静态目录暴露。

日志位于 `.cache/logs/`。健康检查 `/api/health` 只表示服务存活；行情是否更新看界面获取时间或 `/api/dashboard` 的 `snapshot.fetchedAt`。备份 `.cache/v2/ledger/`、账号与评论数据库、管理配置；数据库需使用在线备份接口，详见 [账号与邮箱](accounts.md)。

前台运行 `npm run local` 时可用 Ctrl+C 停止。后台启动的进程号记录在 `.cache/server.pid`，停止前应核对该进程命令行确为本项目 `app/server.mjs`，再停止进程。暂未设置开机自启。

## 公网入口

当前选定 **腾讯云香港轻量服务器**，先按月试用。部署包、安装、备份和上线步骤见 [腾讯云香港部署](tencent-cloud.md)。独立服务器使网站不依赖玩家电脑开机。

如继续采用本机托管，可以使用固定域名加 Cloudflare Tunnel，将 HTTPS 域名路由到 `http://127.0.0.1:8787`；不需要直接开放本机服务端口。

根据 [Cloudflare 官方部署文档](https://developers.cloudflare.com/tunnel/get-started/)，发布应用需要 Cloudflare 账号和域名。尚未准备这些条件时，继续使用现有云端公开网址。

[Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) 只适合临时联调：地址会变，没有可用性保证，最多200个进行中的请求。它没有在本项目中被当作正式公测入口启用。

## 容量与运维

- 玩家读取共享看板缓存；采集不随访客人数成倍增加，刷新租约合并重复请求。
- 看板支持短时 HTTP 缓存、ETag；本机启用 gzip 和压缩结果复用。
- 每个来源地址每分钟最多300次请求。腾讯云部署通过本机 Nginx 覆写真实来源地址，并启用 `TRUST_PROXY=loopback`，让不同访客独立计数；默认本机运行不信任转发头。不要对未知代理直接启用该选项。
- API 不接入游戏账号、付款或自动交易。玩家账号用于评论和条件同步，写入需验证身份；历史接口只接受固定格式物品 ID。
- 当前仅完成本机并发抽测，未承诺可承载的在线人数。公测关注响应时间、CPU、内存、上行流量和采集失败率，再决定扩容。
- 用户增长后可迁移到常在线服务器，保持 Node 服务与数据目录即可；云端托管版继续使用 R2。

## 云端构建

运行 `npm ci`、`npm run build`，使用原有 Sites 项目身份发布。`.openai/hosting.json` 不应换成新站点 ID。

访问时可以触发后台刷新，返回已有快照。无访问期间的独立计划目前处于停用状态；需要全时采集时再启用实际调度，不把浏览器轮询当成后台任务。
