# 性能记录

日期：2026-10-21。使用相同 PVE 缓存样本：5,480 个物品，1,387 份历史，349,599 个历史点。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 行情 + 标签 JSON（十进制 MB） | 36.18 | 6.11 |
| 同为 gzip 的数据量 | 4.87 MB | 0.88 MB |
| 全样本标签分析（5次均值） | 97 ms | 17 ms |

数据量不含配对收益档案、图片和静态脚本；性能来自本机 Node 固定样本，不是公网首屏耗时或线上容量承诺。

## 调整

1. 将历史点整理为7日参照、近期复核点和逐日中位数。仍按玩家技能计算手续费，不能把统一税率的结果直接套给所有人。
2. 首屏一次读取行情、标签摘要及配对收益；详情原始走势图按需下载。
3. 删除传输中的未使用字段和非最优商人回收价，保留全部物品、进货路线及必要交易条件。
4. 后台采集与前台读取分开，过期缓存立即返回，重复更新通过租约合并。
5. 本机 gzip、ETag 和压缩结果复用；前端缓存同一物品的判定，市场切换取消旧请求。
6. 标签与列表准备完成后统一显示，失败提供重试；不增加人为最低加载时长。

## 准确性验证

使用优化前的模型逐条比较三个手续费条件，共4,161次历史判定，结果一致；全部物品的拾取、物品一览、倒货、制作收益在传输裁剪前后保持一致。
