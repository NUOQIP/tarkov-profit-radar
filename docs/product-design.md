# 产品行为与边界

更新：2026-10-21。目标是玩家在桌面宽屏、笔记本、平板和手机上快速判断捡取、出售、倒货和制作，同时兼顾游戏旁屏使用。

## 旁屏与活动开关

主要功能分为捡卖、商人倒货、藏身处三个独立大页签，另有物品一览。取消自选大屏，旧大屏链接转到捡卖页。参考《明日方舟》的工业界面语汇，使用蓝灰底、硬边卡片、地形细线、金色标记和低干扰动效，搭配大金额、实际物品图和少量关键指标；支持深浅外观及减少动态效果偏好。宽屏侧栏导航、手机底部导航，列表随窗口宽度增加列数，低高度窗口压缩工具栏。筛选、条件设置和物品详情使用抽屉，将主要空间留给列表。

捡卖页严格按单格净到手倒序；倒货页按每次净利，藏身处页按每批最终净利润，时薪仅作参考。收藏用独立筛选，不改变排序。每个页签独立记住分类、搜索和7日急涨筛选。长线高值只保留绿色标记，移除独立长线筛选。活动开关按市场共用；移除单件 / 满堆叠切换和卡片小折线图，保留详情中的出售数量试算。底部移除计算口径与历史按钮，替换为标准 / 紧凑两档密度切换。

四个页签始终可见，不提供持久隐藏操作并忽略旧隐藏记录。每页列表独立滚动，切页保留位置。自动更新取得完整快照后，同时重算数值与排序。滚动或打开详情时暂存新行情；结束后保留可见条目位置。可暂停自动应用或手动应用新行情。页面恢复可见时补查过期快照。

每件源物品都保留，包括活动限定、禁售物品和货币。推荐层去重整枪预设并排除货币；数据库条数不等于可推荐条数。“活动限定”默认关闭、按市场保存，打开后纳入已识别活动道具、依赖活动材料的兑换和季节工位制作。关闭不删除记录或收藏。规则由明确 ID 清单维护，缺少完整刷新资料时不宣称知道全部地图、活动开启状态和获取概率。

## 收益与个人条件

捡取显示单件可用出售渠道的净到手除以占格；倒货扣进货或兑换成本；制作扣消耗材料与税费，不计燃料运行分摊。情报中心固定3级，管理技能可修改，手续费参数来自各市场当前快照。

工具不按批消耗，首购资金单列。材料统一采用采购成本，跳蚤参考当前最低价与24小时均价中较高者，并与已解锁商人价格比较。默认满商人、满设施、任务全完成。界面不再提供材料成本口径或游戏版本切换。

首次打开预选全任务完成、商人最高级。玩家及所有设施等级固定为最高级。“我的条件”保留管理技能、实际交易商人的忠诚度、任务复选框；生产设施以复选框决定是否参与制作推荐，不显示非生产设施或设施等级。商人显示英文名，排除剧情角色。编辑按市场保存并影响估值和执行条件，可一键恢复满进度。工具首购金额独立列出，不按批重复扣除。时长使用源配方基础时长，尚未模拟制作技能加速。

倒货和制作默认显示盈利与亏损条目，按最终净利润倒序，酿酒等暂时亏损的配方仍可查看。近战武器、武器预设、直购和兑换统一列出，没有互斥的倒货类型或货源范围切换。武器预设按自身购买 / 兑换成本，使用对应基础武器的市场报价计算回款并扣除手续费；配件收入为零，不提供拆卖模式。非武器的装备预设保留原估值。缺报价或成本的倒货货源保留未知值并排最后，无法进入仅看条件满足。

未确认条件的机会可以浏览，“仅显示条件已确认”会过滤。实际剩余商人库存仍需游戏内确认。计算设置、工具、收藏和显示偏好仅保存在设备本地，可以导出 / 导入。

捡卖默认选中“全部物品”，“跑刀杂物”只包含交换品、饮食和情报，按品类划分而非地图刷新率。升级时所有市场的旧默认范围一次性改为全部物品，此后记住手动选择；旧版设置导入也兼容这一迁移。列表同时显示最低价和24小时均价。详情提供批量出售数量试算，以及真实 7 / 30 日走势、成本拆解和目标挂价、24小时均价、回到 7 日常态的税后试算。走势图支持指针与键盘逐点查看日期和价格；移除重复长说明与收益拆解中的占格。场景保留当前材料成本，不冒充历史利润或预测。

## 长短线

红底“7日急涨”只代表产物售价相对约7日前上升：参照取距今6–8日前有效报价中位数，需至少2条参照报价、此前8至1日的历史覆盖至少6日。当前价格高20%以上，税后增收至少10%，近4小时有两个间隔至少15分钟的高价确认，最近两条也须保持高位，当前报价必须在60分钟内且至少3条。不要求最近24小时继续上涨，小额真实增收也可识别。高价、高利润或材料降价本身不触发红色。

拾取绿色依据至少 24 个完整日的价格，按现行费用回算：至少80%的日期及下四分位达到每格30,000 ₽，当前也达到门槛。倒货与制作绿色需要自采、版本及角色条件一致的配对成本档案，不能只用产物价格史。兼具长短线保留双标签，优先浅红底；证据不足保持中性。

历史逐批核验，优先高值与涨价候选，不在底部持续显示核对过程。没有历史则不绘制假曲线或生成标签。

## 刷新与边界

三个市场的价格、历史与角色条件完全分开。前台每 5 分钟检查；成功数据持久化。获取时间和逐物品报价时间分开，1–6 小时延迟报价只供估算，不进入短线和“仅显示条件已确认”。失败保留最后成功值，不用零成本或其他市场补价。
