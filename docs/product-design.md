# 产品行为与边界

更新：2026-10-22。目标是玩家在桌面宽屏、笔记本、平板和手机上快速判断捡取、出售、倒货和制作，同时兼顾游戏旁屏使用。

## 旁屏与活动开关

主要功能分为捡卖、商人倒货、藏身处三个独立大页签，另有物品一览。取消自选大屏，旧大屏链接转到捡卖页。参考《明日方舟》的工业界面语汇，使用蓝灰底、硬边卡片、地形细线、金色标记和低干扰动效，搭配大金额、实际物品图和少量关键指标；支持深浅外观及减少动态效果偏好。宽屏侧栏导航、手机底部导航，列表随窗口宽度增加列数，低高度窗口压缩工具栏。筛选、条件设置和物品详情使用抽屉，将主要空间留给列表。

捡卖的全部物品按单件总净利倒序，跑刀速览按单格净到手倒序；倒货页按每次净利，藏身处页按每批最终净利润，时薪紧邻用时，仅作参考。收藏用独立筛选，不改变排序。每个页签独立记住分类、搜索和涨价机会筛选。长线高值只保留浅金色标记，移除独立长线筛选。活动开关按市场共用；移除单件 / 满堆叠切换和卡片小折线图，移除卖价及出售数量试算。底部移除计算口径与历史按钮，替换为标准 / 紧凑两档密度切换。

四个页签始终可见，不提供持久隐藏操作并忽略旧隐藏记录。每页列表独立滚动，切页保留位置。自动更新取得完整快照后，同时重算数值与排序。新行情暂存后显示15秒自动应用倒计时；滚动和打开详情不会重置计时，应用时保留可见条目位置与明细滚动位置。可暂停计时、恢复继续或立即应用。页面恢复可见时补查过期快照。

每件源物品都保留，包括活动限定、禁售物品和货币。推荐层去重整枪预设并排除货币；数据库条数不等于可推荐条数。“活动限定”默认关闭、按市场保存，打开后纳入已识别活动道具、依赖活动材料的兑换和季节工位制作。关闭不删除记录或收藏。规则由明确 ID 清单维护，缺少完整刷新资料时不宣称知道全部地图、活动开启状态和获取概率。

## 收益与个人条件

捡卖的全部物品以单件最佳渠道净到手为大字，标为“净利 / 个”，按此总值排序，单格值作为次要指标；跑刀速览的图标云与列表保留单格大字及排序。商人对比显示“较 XX ± 差值”，差值为跳蚤税后净到手减最佳商人回收价，无法比较时显示未知。倒货扣进货或兑换成本；制作扣消耗材料与税费，不计燃料运行分摊。情报中心固定3级，管理技能可修改，手续费参数来自各市场当前快照。弹药包的计税基础价值加上所含弹药的基础价值，不将单发禁售状态传递给封装弹药包；数量只乘一次。

工具不按批消耗，首购资金单列参考。移除“我已持有”勾选及工具确认限制，旧的工具持有记录不再影响显示或筛选。材料统一采用采购成本，跳蚤采用当前最低价，24小时均价单列供参考，并与已解锁商人价格比较。默认满商人、满设施、任务全完成。界面不再提供材料成本口径或游戏版本切换。

首次打开预选全任务完成、商人最高级。玩家及所有设施等级固定为最高级。“我的条件”保留管理技能、实际交易商人的忠诚度、任务复选框；生产设施以复选框决定是否参与制作推荐，不显示非生产设施或设施等级。商人显示英文名，排除剧情角色。编辑按市场保存并影响估值和执行条件，可一键恢复满进度。工具首购金额独立列出，不按批重复扣除。时长使用源配方基础时长，尚未模拟制作技能加速。

倒货和制作默认显示盈利与亏损条目，按最终净利润倒序，酿酒等暂时亏损的配方仍可查看。近战武器、武器预设、直购和兑换统一列出，没有互斥的倒货类型或货源范围切换。武器预设按自身购买 / 兑换成本，使用同型号默认整枪的市场报价计算回款并扣除手续费，不套用裸机匣或稀有改装预设的独立报价；配件收入为零，不提供拆卖模式。非武器的装备预设保留原估值。缺报价或成本的倒货货源保留未知值并排最后，无法进入仅看条件满足。

未确认条件的机会可以浏览，“仅显示条件已确认”会过滤。实际剩余商人库存仍需游戏内确认。计算设置、收藏和显示偏好仅保存在设备本地，可以导出 / 导入。

捡卖默认选中“全部物品”，“跑刀速览”默认勾选交换用品、饮食、情报、弹药包、医疗物品和海报，按品类划分而非地图刷新率。旧的五类默认选择自动补入海报一次，自定义选择和后续手动取消保留。物品类型和有级价值滑条由图标云、列表共用，默认5万/格至无上限；“恢复默认”常驻快捷区，与“看看钥匙”“看看装备配件”并排，不保留“看看杂物”按钮。升级时所有市场的旧默认范围一次性改为全部物品，此后记住手动选择；旧版设置导入也兼容这一迁移。列表同时显示最低价和24小时均价。详情先展示最终收益、净回款和成本，材料需求紧邻成本：图片、数量、单价、合计与采购渠道；工具首购独立标明。移除收益拆解和卖价试算。保留真实 7 / 30 日走势、相关交易路线与执行条件，走势图支持指针与键盘查看日期和价格。藏身处卡片仅保留参考时薪，不再重复产出净值。

## 长短线

“涨价机会”统一使用浅红底，不再提供“待复核”状态，不为凑数量生成信号：

- **7日常态**：前7个完整 UTC 日先各取有效报价中位数，再取日中位数；至少覆盖3日且包含近2日，历史更新不超过24小时。当前售价高出至少15%。
- **24小时急涨**：距今30至6小时内按小时归组取中位数，再取各小时中位数，避免刚出现的高价抬高参照；至少6小时有数据、跨度至少12小时，覆盖18小时前和12小时内。当前售价高出至少20%。
- 两种窗口都要求当前价不低于参照的上四分位水平，税后相较常态出售至少多得10%且有正增收；常态净值低于商人回收时采用商人回收作为收益下限。满足任一窗口即可，优先已确认窗口，再选实际增收更大的窗口。
- **浅红**：满足上述涨价及增收条件即可，缺第二次确认、仅3–9条报价、报价延迟1–6小时的机会同样标红。少于3条、无效或过期报价仍不列为涨价机会，少于10条报价保留独立风险标签。
- 后台保留独立扫描的确认信息，供分析和选择参照窗口使用，不再决定前台是否标红。同一上游扫描时间无论被抓取多少次都只计一次。
- 卡片仅展示参照窗口与涨幅，详情保留参照价；移除额外“多到手”提示。增收按每件 / 每次 / 每批数量计算；弹药等低单价物品也按比例识别，不以单件金额门槛排除批量卖出的机会。高价、高利润、材料降价本身不触发信号；倒货和制作还须当前净利大于零。

后台保留真实扫描时间与报价数量，滚动积累36小时观察，并限制传输体积。历史摘要更新与即时扫描分开计时；刷新优先关注涨价线索，同时保留名额刷新旧物品和发现新物品。失败请求退避，不会持续占满扫描队列。

拾取浅金色依据至少 24 个完整日的价格，按现行费用回算：至少80%的日期及下四分位达到每格30,000 ₽，当前也达到门槛。倒货与制作浅金色需要自采、版本及角色条件一致的配对成本档案，不能只用产物价格史。兼具长短线保留双标签，优先浅红底；证据不足保持中性。

历史逐批核验，优先高值与涨价候选，不在底部持续显示核对过程。没有历史则不绘制假曲线或生成标签。

## 刷新与边界

三个市场的价格、历史与角色条件完全分开。前台每 5 分钟检查；成功数据持久化。行情、历史摘要与收益档案合并读取，判定完成后一次展示；完整走势图按需下载。加载期间显示搜索仓库动效，失败可重试。获取时间和逐物品报价时间分开，1–6 小时延迟报价只供估算，满足涨价条件时同样标红，但不进入“仅显示条件已确认”。失败保留最后成功值，不用零成本或其他市场补价。
